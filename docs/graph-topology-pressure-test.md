# Graph topology pressure test

Status: working architectural judgment, not a settled sitemap.

Sources compared:

- legacy website inventory
- `Websiste legacy content .docx`
- LearnGraph Project Presentation, midi version
- Afghan Women Project material, used to understand intent and possible applications rather than to claim completed work
- current graph topics and article scaffold

## Verdict

The four root territories still provide a credible first orientation. The equal four-topics-per-territory structure does not survive contact with the material.

The website needs variable-density clusters, typed content, and meaningful cross-territory relationships. It should not manufacture topics to preserve visual symmetry or turn every useful example into an audience page.

## Pressure by territory

### Platform — strong, coherent

The current core holds:

- the shared/living model
- personal paths
- evidence and visible progress
- sovereignty

`Inside LearnGraph` supplies concrete product material for these topics. “Knowledge that travels and returns” deepens the model, evidence, and interoperability story; it does not necessarily require another node.

### Collaborate — strong but internally split

Two different kinds of collaboration currently share one territory:

1. transformation services: process clarity, automation, product/service development
2. LearnGraph application and partnership: educational pilots, foundations, protected learning contexts, implementation partners

This is the strongest pressure toward internal clustering. `Work together` is too generic to carry both worlds. Cases should substantiate the relevant service or application rather than become a detached trophy cabinet.

### About — coherent, but one false slot

`Why LearnGraph`, people, and network are real topics. Contact is a utility action, not an editorial topic.

The missing substantive address is LearnGraph's commitment to learning access under unequal conditions. The Project Presentation and Afghan pilot material show that this is not a campaign label; it is part of why the system exists. Possible working labels include `Learning access`, `Commitment`, or `Why access matters`. The label must not imply that proposed impact has already been achieved.

### Research / Open Source — valid intent, thinner public evidence

Open core, interoperability, research questions, and contribution form a plausible cluster, but publication must follow actual artifacts. This territory should be allowed to launch with fewer nodes rather than filling space with aspiration.

`Open work` may eventually be a more honest public label than a broad `Research` claim, depending on available repositories, papers, standards work, and collaborations.

## Content that is not a territory

- vocational education, labour-market systems, individual learners, and enterprise learning are applications or examples, not automatic navigation roots
- cases are evidence attached to claims
- contact, launch-app, language, consent, and legal material belong to the interface shell
- audience-specific repetition should not return disguised as graph nodes

## Working topology to test

- **Platform** — model, personal paths, evidence, sovereignty
- **Collaborate**
  - service cluster — process clarity, automation, product/service development
  - application/partnership cluster — educational pilots, foundations, protected or context-specific learning
- **About** — why LearnGraph, learning access/commitment, people, network
- **Research / Open work** — only the open-core, interoperability, research, and contribution nodes supported by real public work

The child counts should be unequal. A node may contain an article, case, video, diagram, evidence block, links, or a deliberate combination; the current paragraph-only article schema is too narrow.

## Visual consequence

Do not restyle the graph yet merely to fit more circles. First encode the variable topology and identify real relationships. Then test whether the current abstract Zone can express it.

If not, a molecular cluster view is a strong next direction: roots remain orientation anchors, while unequal topic groups form local constellations around them. Geometry should reveal clustering and cross-links rather than preserve fourfold symmetry.

## Decisions still requiring owner truth

- which open-core, self-hosting, integration, portability, and sovereignty claims are true now versus direction
- which partners, team members, quotes, videos, and cases are current and publishable
- whether transformation services and LearnGraph partnerships should remain one root with visible subclusters or become separate roots
- what public artifacts justify the Research / Open Work territory at launch
