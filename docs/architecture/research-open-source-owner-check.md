# Research / Open Source owner check

Purpose: determine launch visibility and publication status. This is not a request for marketing language.

For each item, record `NOW`, `DIRECTION`, `NO`, or `UNKNOWN`, plus an owner and an inspectable artifact where one exists.

| Question | Status | Owner | Artifact / note |
|---|---|---|---|
| Is the frontend repository intentionally public and suitable for linking from the website? | UNKNOWN |  |  |
| Is CC BY-NC 4.0 the intentional and appropriate license for that repository? | UNKNOWN |  |  |
| What exact components constitute the current open core? | DIRECTION / UNKNOWN |  |  |
| Can an external party currently self-host a supported LearnGraph deployment? | UNKNOWN |  |  |
| Which APIs, schemas, imports/exports, standards mappings, or interoperability artifacts are currently public? | UNKNOWN |  |  |
| Which research work or named research collaborations are active and publishable? | UNKNOWN |  |  |
| Are external contributions currently accepted and supportable, and under which governance/licensing rules? | UNKNOWN |  |  |

## Decision rule

- `NOW` without an artifact supports only a carefully scoped factual statement.
- `NOW` with an inspectable artifact may support a public node.
- `DIRECTION` remains backlog or explicitly labelled roadmap.
- `UNKNOWN` remains hidden until an owner resolves it.
- `NO` removes the claim from the current publication plan.

The territory becomes launch-visible only when enough material answers a distinct visitor question without relying on aspiration to fill the graph.
