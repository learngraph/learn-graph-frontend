# Legacy content inventory and migration map

Status: first-pass inventory only; no copy has been rewritten.  
Scope: the legacy public site implemented under `src/pages/landing`, `src/pages/customerGroups`, `src/pages/service`, `src/pages/legal`, shared global components, and apparently intended but unreachable legacy content. The new `GraphWebsite` and `src/content/nodes` are excluded as source material; their four territories are used only as proposed destinations.

## How to read this inventory

- Every action and target is a **migration hypothesis**, not an editorial decision.
- Translation variants are treated as one content unit. English wording is used to identify claims. Source copy generally lives in `src/i18n/locales/en.json`, with parallel dictionaries in `de.json`, `el.json`, `fr.json`, `es.json`, and `ar.json`.
- `en` and `de` contain all 306 leaf keys. `el`, `fr`, `es`, and `ar` each contain 236 and omit all 70 `service.*` keys; the runtime falls back to English for those keys (`src/i18n/i18n.tsx`).
- `source-material/raw` also contains the uploaded Project Presentation and Afghan Women Project `.docx` files. They were intentionally excluded from this legacy-site inventory and must be reviewed as a separate source corpus before editorial migration.
- “Platform”, “Collaborate”, “About”, and “Research” below are proposed canonical territories. A slash-separated suffix is a suggested topic, not necessarily an existing slug.
- Confidence refers to the inventory/mapping judgment, not the truth of a marketing claim. Quantitative claims and case/proof claims still require source verification.
